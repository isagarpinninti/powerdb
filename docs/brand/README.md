# Brand

The mark is a **P** made of a stem and two stacked bars: a record (white) and the file attached to it (amber), joined to one stem.

| File | Use |
|---|---|
| `logo-mark.svg` | The tile: dark rounded square with the mark. App icon, favicon, social image. |
| `logo-mark-light.svg` | The mark alone, dark on a light background (no tile). |
| `logo-1024.png`, `logo-256.png` | PNG exports of the tile. |

Colours: tile `#0a0a0b`, mark `#fafafa`, accent `#f59e0b` (`#d97706` on light backgrounds). Keep clear space of one bar-width around the mark and do not stretch, recolour or rotate it. Do not draw it below 16 px; at 16 px use the tile.
`desktop/scripts/make-icon.py` regenerates the app icon files from the same geometry.
