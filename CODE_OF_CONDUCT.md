# Code of conduct

This is a small project. The rules are short.

- Be direct and kind. Disagree about the work, not the person.
- No harassment, no discrimination, no personal attacks, and no publishing other people's private information.
- Assume good faith when something is unclear, and ask before concluding otherwise.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block people who keep doing it.

To report a problem, message the repository owner privately through GitHub. Reports are read by the maintainer and kept confidential.
