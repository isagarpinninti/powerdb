# Getting help

1. [docs/GUIDE.md](docs/GUIDE.md) has a "When something goes wrong" section with the problems people hit most.
2. Search the existing [issues](https://github.com/isagarpinninti/powerdb/issues).
3. Open a new issue using the bug report form. The version, how you run it and the logs are what make a problem solvable.

PowerDB is maintained by one person without a support contract: there is no guaranteed response time. Security problems go through [SECURITY.md](SECURITY.md), not the issue tracker.
